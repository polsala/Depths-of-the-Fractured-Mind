# Save and Continue

The title screen offers **Continue**, **Import Save**, **Export Save** and **Delete Save** when appropriate. Starting a new run or importing over an existing run asks for confirmation. Exploration also offers **Save Now**, **Export Save** and **Save & Return to Title**. The game auto-saves after gameplay updates and on page exit.

Saves are kept in this browser's local storage under `depths-of-the-fractured-mind.run.v1`. They are not synchronized between devices. Export a JSON backup before clearing browser data or moving devices. Storage may be unavailable in private browsing or when quota is exhausted; the UI reports failure instead of claiming success.

Version 2 snapshots contain the complete party, inventory and equipment, current mode/location, all generated depth maps and mutable tiles, fog/visited tiles, moral/event/boss flags, active event or combat, procedural event cooldown and the current deterministic RNG state. They add optional authored layout/feature IDs, intake mechanism/reward/perception flags, an exploration notice and wounded enemies retained after fleeing the intake fight. Combat snapshots resume at a completed action boundary; the combat party is re-linked to the main party during loading. Camera interpolation, input queues, audio playback and rendering caches are recreated, not serialized.

The loader validates the schema before replacing an existing run. Unsupported newer versions and malformed saves stay available for export or deletion; they are never silently overwritten. Version 1 loads without replacing its procedural maps or inventing intake progress. The pre-release version 0 format receives empty completed-event tracking and a deterministic fallback RNG state. The writer uses v2 at the existing storage key. No version 0 public release existed. The immutable `tests/fixtures/saves/v1/` corpus and browser continuation tests protect map, event, combat, party and random-stream compatibility.

Known limitations: browser storage is local to one origin; cross-device progress requires manual export/import. Existing ending state and final choices persist, but automated continuation does not establish artistic or campaign playtest approval.
