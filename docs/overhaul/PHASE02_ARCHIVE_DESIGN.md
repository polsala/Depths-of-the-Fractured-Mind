# Phase 02 — The Archive design candidate

Date: 2026-11-10. Baseline: clean `main` at `96a2d0aae7c3384379885624d6df687275e5db5f`. This implementation follows the owner's Phase 02 instruction; the historical 01A/01B human acceptance gates remain open. Character identities remain canonical in `docs/design.md`.

## Player promise and loop

Read the building that decided which accounts survived. Navigate filing ranks, inspect the interrupted record, and decide how the companions confront responsibility. The dramatic question is **who gets to decide what happened?**

The player follows functional connections, confronts the existing Riot Recording and Broken Floor choices, finds finite optional supplies and prepares for the existing guardian. Decisions change the established SAN/morality/story state; the level adds no alternate combat or narrative identities. Loss remains the existing party-defeat flow. Supplies and the optional evidence release support preparation without becoming mandatory keys.

The intended rhythm is orientation → compression → scale → landmark/rest → responsibility → damage/rescue → preparation → guardian. This is a design hypothesis until first-time player sessions establish pacing and orientation. Generation/reachability tests do not establish fun.

## Architectural brief

Institutional concrete, ink enamel steel, indexed drawers, paper tabs, retrieval machinery, service apertures and restricted doors belong to the same complex as Intake. Avoid fantasy shelves, magical books and decorative medieval fixtures. Palette roles: umber `#2c231d`, paper `#a99b7c`, institutional ink `#4b6970`, task amber `#d2ad69`.

One grid cell remains 2 m, eye height 1.6 m and CameraRig FOV/timing remain unchanged. Static room modules share materials and instanced geometry. Localized handles, label pockets, rails, recessed panels and contact details carry scale; sparse cancelled labels and missing files communicate concealment. Task lights reveal human work; cool strips organize storage; security fixtures identify restricted access. No bloom or screen shake is required for meaning.

No binary environment media is imported in this pass. Source geometry and procedural surface/signage recipes are original code-authored candidates, tracked separately in the provenance ledger. They need human originality/contributor and artistic review; legacy textures/audio retain their existing status. The environment is not certified premium merely because its geometry is detailed.
